### Project Description
**WISH: time locked** is a cinematic, emotional web experience where you can literally stop time on a living analogue clock. When time freezes, a soft voice whispers "I will wait for you," gentle music plays, and you can whisper a wish to the angel — who replies "Nokki irunno ippo kittum🫣." Every moment you keep is saved in a personal Time Capsule you can revisit forever.

### The Problem (that doesn't exist)
Everyone says time stops for no one. So a person can never truly pause a moment they want to hold onto — a last goodbye, a quiet happy second, the exact instant they felt something they can't name. There is no button in real life to freeze the world, whisper a wish, and hear the universe whisper back.

### The Solution (that nobody asked for)
A glowing analogue clock that actually stops when you press "Stop Time." The second hand halts, the room dims, a voice tells you it will wait for you, and an angel listens to your wish before you let time start again. Each frozen moment is locked away in a Time Capsule — a tiny museum of feelings no one asked for, but everyone secretly wanted.

## Technical Details
### Technologies/Components Used
For Software:
- TypeScript, HTML5, CSS3
- React 19, TanStack Start (router + server functions), TanStack React Query
- Tailwind CSS v4 (with native `@theme` tokens and `@utility` rules)
- Vite 8 (build tool)
- Web Speech API (`SpeechSynthesisUtterance`) for the spoken voice
- HTML5 `<audio>` with fade in/out for the waiting tune
- SVG for the hand-drawn analogue clock face
- `localStorage` for persisting the Time Capsule moments

For Hardware:
- None — purely a browser experience.

For Software:
# Installation
```bash
git clone https://github.com/annara-cmd/wish--time-locked
cd wish--time-locked
npm i
```

# Run
```bash
npm run dev
```
Then open the local URL shown in the terminal (default http://localhost:8080).
